> [!WARNING]
> **本版本必须同步升级面板和所有 Agent。**
> 本次修改了面板与 Agent 的认证协议，旧版 Agent 无法连接新版面板。

## 升级说明

升级前请备份面板和 Agent 的数据目录。

- 将面板和所有 Agent 更新到本次 Release 对应版本。
- Docker 部署需要同时更新面板容器和 Agent 容器。
- 更新面板不会自动更新已经安装的 Agent。
- 保留原数据目录，升级后重新登录，并检查所有 Agent 是否在线。
- 使用预发布版本时，两端应使用本次 Release 的精确版本；Agent Docker 安装命令需设置对应的 `DFPANEL_AGENT_IMAGE`。
